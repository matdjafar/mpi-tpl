Bagian 1: Mengapa MPI?

Pergeseran Paradigma: Media Statis vs Media Interaktif

Mengubah peran murid dari sekadar penonton pasif menjadi pelaku aktif belajar.

📕 Media Statis (Pasif)

Aktivitas peserta didik sangat terbatas pada penerimaan informasi:

  • Melihat tayangan slide teks panjang
  • Mendengarkan rekaman ceramah tanpa interaksi
  • Membaca buku teks berlembar-lembar
  • Tingkat retensi pemahaman murid rendah (~10-20%)

✨ Media Interaktif (Aktif)

Peserta didik mengalami siklus belajar langsung:

  • Memilih opsi, menggeser slider, drag-and-drop objek
  • Mencoba simulasi mandiri dan bereksperimen
  • Mendapatkan respons dan umpan balik langsung seketika
  • Tingkat keterlibatan dan pemahaman konsep jauh lebih tinggi
Bagian 1: Mengapa MPI?

Prinsip Interaktivitas: Bukan Sekadar Animasi

Interaktivitas bermakna terjadi ketika tindakan murid memicu proses kognitif.

AKSI MURID ➔ RESPONS SISTEM ➔ UMPAN BALIK ➔ REKONSTRUKSI MAKNA

1. Aksi Murid

Murid menginput variabel, menjawab soal kuis, atau menghubungkan potongan mufradat.

2. Respons Sistem

Aplikasi memproses logika matematis atau kaidah hukum secara seketika di layar.

3. Refleksi & Belajar

Murid melihat akibat dari pilihannya sehingga memahami letak kesalahan atau kebenaran konsep.

Bagian 2: Mengenal MPI

Definisi Media Pembelajaran Interaktif (MPI)

Memahami batasan dan hakikat MPI dalam konteks pembelajaran modern.

"MPI adalah media digital terstruktur yang mengintegrasikan teks, visual, audio, dan logika pemrosesan yang memungkinkan peserta didik berinteraksi secara aktif serta memperoleh umpan balik (feedback) seketika untuk mencapai tujuan pembelajaran tertentu."

🎯 Tujuan Jelas

Fokus pada capaian kompetensi dasar/CP, bukan sekadar hiasan.

⚡ Interaksi Timbal Balik

Aplikasi merespons input peserta didik secara dinamis.

💡 Berdiferensiasi

Murid dapat belajar sesuai dengan kecepatan (*self-paced*) masing-masing.

Bagian 2: Mengenal MPI

Koreksi Konsep: Jangan Terjebak "Interaksi Semu"

Membedakan interaksi bermakna dengan interaksi yang hanya bersifat dekoratif:

❌ Interaksi Semu / Dangkal

  • Klik tombol "Lanjut" hanya untuk membalik halaman teks.
  • Animasi meledak/bergerak yang tidak menjelaskan isi materi.
  • Game hanya kejar skor tanpa menuntut pemahaman konsep mapel.
  • Banyak musik bising yang mengganggu konsentrasi belajar.

✅ Interaksi Bermakna (Pedagogis)

  • Klik objek untuk menguji hipotesis atau melihat dampak rumus.
  • Animasi yang memvisualisasikan cara kerja organ/mesin/kaidah.
  • Tantangan game dibangun langsung dari permasalahan materi pelajaran.
  • Umpan balik yang memandu murid membetulkan cara berpikirnya.

Bagian 4: Peran AI

Sinergi Guru dan AI: Kolaborasi Co-Creator

AI bukan pengganti guru, melainkan asisten teknis cerdas yang mempercepat produksi media.

👨‍🏫 Peran Guru (Pedagogy Master)

  • Menentukan Capaian Pembelajaran (CP) dan Tujuan Pembelajaran.
  • Memahami karakteristik dan gaya belajar murid madrasah.
  • Menyusun alur skenario materi dan interaktivitas yang diinginkan.
  • Melakukan kurasi, validasi, dan memastikan kebenaran konsep mapel.

🤖 Peran AI (Technical Builder)

  • Membantu merumuskan ide aktivitas dan skenario interaksi.
  • Menghasilkan kode pemrograman utuh (HTML5, CSS3, JavaScript).
  • Membuat variasi butir soal, studi kasus, dan logika kuis interaktif.
  • Memperbaiki galat (*debugging*) dan mengubah layout sesuai perintah.

Bagian 5: Arsitektur MPI

3 Pendekatan Moda: Offline, Online, atau Hybrid

Sesuaikan pilihan teknologi dengan kondisi nyata fasilitas dan internet di madrasah:

01
📴 MPI OFFLINE

Single File HTML: Semua kode CSS/JS tertanam utuh. Bisa dijalankan langsung di browser laptop/komputer madrasah tanpa kuota internet sedikit pun.

02
🌐 MPI ONLINE

Cloud & Web Based: Terhubung ke server hosting, database nilai (Google Sheets / Firebase), video streaming YouTube, atau Gemini API.

03
⚡ MPI HYBRID

Fleksibilitas Ganda: Materi dan simulasi inti tetap berjalan mulus saat offline, namun saat ada sinyal internet, skor terkirim ke Google Sheets guru.

Bagian 5: Arsitektur MPI

Kapan Guru Tepat Memilih Pendekatan Offline?

Diagram keputusan untuk efisiensi di madrasah dengan keterbatasan koneksi:

Karakteristik Kondisi:

  • Jaringan internet di madrasah tidak stabil atau kuota terbatas.
  • Pembelajaran dilakukan di laboratorium komputer lokal madrasah.
  • Media disebarkan langsung via Flashdisk atau Bluetooth ke laptop murid.
  • Aplikasi tidak memerlukan penyimpanan riwayat data murid jangka panjang.

Keunggulan & Praktik Terbaik:

  • 100% Bebas Kuota: Murid tidak terbebani biaya paket data.
  • Loading Instan: Tidak ada kendala buffering atau server down.
  • Struktur Ringkas: Cukup satu file `index.html` yang bisa dibuka di browser apapun.
Bagian 5: Arsitektur MPI

Kapan Guru Membutuhkan Pendekatan Online?

Memanfaatkan kekuatan cloud untuk pembelajaran jarak jauh dan otomatisasi rekap nilai:

Karakteristik Kebutuhan:

  • Guru ingin rekap nilai kuis murid otomatis masuk ke Google Sheets.
  • Memerlukan fitur live chatbot bertenaga Gemini AI untuk tutor mandiri.
  • Menyematkan video pembelajaran resolusi tinggi dari YouTube / Google Drive.
  • Media diakses murid melalui smartphone masing-masing di rumah via tautan web.

Contoh Implementasi:

  • MPI kuis yang terhubung via Google Apps Script (GAS).
  • Web pembelajaran yang dihosting di GitHub Pages atau Vercel gratis.
  • Chatbot tanya-jawab materi fikih/sains yang memanggil API AI.
Bagian 5: Arsitektur MPI

Kapan Memilih Hybrid & Prinsip Golden Rule

Kombinasi terbaik antara keandalan offline dan kecanggihan online:

💡 Solusi Hybrid untuk Madrasah:

Seluruh konten pembelajaran, animasi, dan simulasi bekerja 100% secara offline di perangkat murid. Ketika murid menyelesaikan kuis dan perangkatnya tersambung ke WiFi/internet, skor langsung disinkronkan ke spreadsheet guru.

⭐ "Golden Rule" Pemilihan Teknologi:

"Pilihlah teknologi yang paling sederhana yang mampu mencapai tujuan pembelajaran secara optimal."
Teknologi mengikuti pedagogi, bukan sebaliknya. Jangan memaksakan teknologi rumit jika solusi sederhana sudah menyelesaikan masalah.

Bagian 7: Alur Kerja

Generate AI Bukan Langkah Terakhir!

Siklus iterasi adalah kunci menghasilkan media pembelajaran yang sempurna.

PROMPT ➔ GENERATE ➔ PREVIEW DI BROWSER ➔ TEMUKAN KEKURANGAN ➔ REVISI PROMPT

💡 Fakta Lapangan:

Hasil kode pertama dari AI jarang sekali langsung 100% sempurna sesuai imajinasi guru. Bisa saja tombol kekecilan di HP, penjelasan soal kurang lengkap, atau warna kurang kontras.

🎯 Kunci Keberhasilan:

Lakukan minimal 2 hingga 3 kali iterasi prompt perbaikan. AI sangat cerdas dalam menuruti instruksi spesifik seperti "Ubah skor agar bertambah 10 jika benar".

Bagian 9: Publikasi & Distribusi

Bagaimana Cara Membagikan MPI kepada Peserta Didik?

Dua jalur distribusi praktis tanpa biaya sewa server yang mahal:

📴 Jalur Offline (Madrasah)

  • Flashdisk Guru: Salin file `index.html` ke seluruh PC di laboratorium komputer.
  • Jaringan Lokal (LAN / WiFi Sekolah): Pasang file di satu komputer server lokal tanpa perlu internet keluar.
  • Direct Share: Kirim file via WhatsApp Web / Bluetooth ke laptop murid. Cukup klik ganda untuk membuka.

🌐 Jalur Online (Gratis & Cloud)

  • Google Apps Script (GAS): Tanam kode HTML di proyek Apps Script dan publikasikan sebagai Web App.
  • GitHub Pages / Vercel / Netlify: Upload file HTML untuk mendapatkan tautan web permanen resmi.
